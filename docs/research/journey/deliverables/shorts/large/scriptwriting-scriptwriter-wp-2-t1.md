# Write 5 Shorts scripts on AI tools

By scriptwriting/scriptwriter. Status: approved.

Audience: General viewers curious about AI tools, including beginner creators and coders
Channel: YouTube Shorts (vertical, under 60s)
Locale: en

GENERAL NOTE: Every demo must actually be run and recorded by the creator. Lines in [brackets] are filled in from what really happens; no result is assumed. Nothing claims news, trending status, new features, pricing, free-tier limits or versions.

=== SCRIPT 1: Same Question, Google vs Perplexity ===
HOOK (0-4s): "Same question, two tools. Let's see how the answers differ."
BODY (4-38s): "I'm typing one question into both, word for word. [Run both live and record.] Look at how each presents its answer. One gives you a page of links to explore. The other may write a summary. [Say what you actually saw.] Check whether the summary shows where its information came from, then open one source yourself. AI answers can be wrong, so that step matters. Which one suits you depends on the question."
CTA (38-44s): "Comment a question you want me to test next."
VISUALS: Split screen, same question typed in both; screen recording; zoom on the sources area; text overlay 'Check the source'.
EST. DURATION: ~40s (about 100 spoken words).
UNVERIFIED / TO CHECK: whether Perplexity currently shows sources beside answers (check the product); current features and pricing (vendor site); terms for showing both products on screen; the creator's actual results.

=== SCRIPT 2: Turn a PDF Into a Podcast ===
HOOK (0-4s): "Let's try turning a PDF into something you can listen to."
BODY (4-40s): "I'm using NotebookLM, a Google tool for working with your own documents. I upload a PDF, then look for an option that creates an audio overview. [Run it and record each step.] Now I'll play a few seconds. [Say honestly how it sounds and how well it matches the document.] Always compare what you hear with the original, because summaries can miss or get things wrong. Use a document you're allowed to upload."
CTA (40-46s): "Follow for more tools I actually test."
VISUALS: Screen recording of upload and audio option; waveform over the audio; overlay 'Compare with the original'.
EST. DURATION: ~42s (about 100 words).
UNVERIFIED / TO CHECK: that NotebookLM currently offers an audio overview and where the option sits; availability, limits and pricing (Google's pages); rules on uploading documents; terms for on-screen use; the creator's actual output quality.

=== SCRIPT 3: Describe an App, Build It with Cursor ===
HOOK (0-4s): "Can I build a tiny app just by describing it? Let's find out."
BODY (4-42s): "I'm opening Cursor, an AI code editor. My request is one plain sentence: [state the exact small app, e.g. a simple to-do list]. [Run it and record the whole attempt, including errors.] Now I'll run what it wrote. [Say honestly whether it worked, what broke, and what you fixed.] AI-written code can have bugs, so read it and test it before you rely on it. Even if it's imperfect, you can see how far one sentence gets you."
CTA (42-48s): "Tell me what app I should try next."
VISUALS: Screen recording of the prompt, generated code and running app; overlay with the exact prompt; show errors if any.
EST. DURATION: ~45s (about 105 words).
UNVERIFIED / TO CHECK: Cursor's current features and interface; pricing and plan limits (vendor pricing page); terms for on-screen use; whether the chosen app really builds; the creator's actual results.

=== SCRIPT 4: Voiceover From Text with ElevenLabs ===
HOOK (0-4s): "Let's turn plain text into a voiceover and judge it honestly."
BODY (4-40s): "I'm using ElevenLabs, a text-to-speech tool. I paste in a short script and pick a voice. [Run it and record.] Here's the result. [Play 5-8 seconds. Say honestly how natural it sounds.] Listen for odd pauses or words it gets wrong. Before using any voice in your videos, check the terms and make sure you have the right to use it. Some tools also ask you to disclose AI voices."
CTA (40-46s): "Want a side-by-side of voices? Comment below."
VISUALS: Screen recording of text input and voice choice; play audio over captions; overlay 'Check the terms'.
EST. DURATION: ~42s (about 100 words).
UNVERIFIED / TO CHECK: ElevenLabs' current features, free-tier limits, pricing and commercial-use terms (vendor pricing and terms pages); YouTube's current AI-disclosure rules; whether the voice used may be shown on screen; the creator's actual audio quality.

=== SCRIPT 5: 3 Prompts That Might Save You an Hour ===
HOOK (0-4s): "Three prompts to try for your own busy work."
BODY (4-44s): "Works with an AI assistant like Claude or ChatGPT. One: paste a long email thread and ask for a short summary with action items. Two: paste rough notes and ask it to turn them into a clear checklist. Three: describe a task and ask for questions it needs answered before it starts. [Run each on harmless sample text and record, saying honestly how much time it saved.] Always read the output before you use it, and never paste private information."
CTA (44-50s): "Save this and try one today."
VISUALS: Three numbered cards with the prompt text; screen recording of each run; overlay 'No private data'.
EST. DURATION: ~46s (about 110 words).
UNVERIFIED / TO CHECK: the 'saves an hour' effect is not measured, so the creator should time it or soften the title; which assistant and model version is shown; terms for on-screen use; the creator's actual results.
