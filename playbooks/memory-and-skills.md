# Memory and skill policy

What each level retrieves, and when. Code enforces the limits: a brief has a token budget, a task's memory is a few top hits from each tier, and a whole memory bank never reaches a prompt.

## ceo

Recall memory only for a specific question.

## manager

Recall memory only for a specific question.

## staff

Recall memory only for a specific question. memory_write is private to you: save only what you'd want next time.
